# 🎓 Campus Companion
### Student Management & Productivity System

Campus Companion is a simple Python-based student management and productivity system designed to help students manage their academic information in one place.

The project is developed using basic Python programming concepts and file handling, making it suitable for beginners and first-semester CSE students.

---

## 🚀 Features

### 👤 1. Student Profile
- Create and update student profile
- Store:
  - Name
  - Roll Number
  - Branch
- View saved profile information

### 📊 2. Attendance Management
- Enter subject-wise attendance
- Calculate attendance percentage
- Display attendance status
- Calculate overall attendance
- Save attendance data to a file

### 📈 3. Marks Management
- Enter subject-wise marks
- Calculate percentage
- Automatically assign grades
- Calculate overall percentage
- Save marks data to a file

### 📅 4. Timetable
- Display weekly class timetable
- Organize subjects according to days

### ✅ 5. Task Manager
- Add academic or personal tasks
- Set task priority:
  - High
  - Medium
  - Low
- Mark tasks as Pending or Completed
- Save task information

### 💾 6. Saved Data
- View previously saved:
  - Student Profile
  - Attendance
  - Marks
  - Tasks

### 📊 7. Student Dashboard
The dashboard provides a quick academic summary including:
- Student profile
- Overall attendance
- Overall marks percentage
- Pending tasks
- Completed tasks
